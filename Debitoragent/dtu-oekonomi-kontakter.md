# DTU Økonomi — Contact Routing Guide

**Source:** Two DTU org charts, May 2026 — *Organisationsdiagram – Projektøkonomi* and *Organisationsdiagram – Budget og Rapportering*.
**Purpose:** Route a question to the right person based on which department (institut/område) it concerns.

---

## How to use this file

1. Identify the department number or name in the question (e.g. "01", "DTU Compute", "Compute"). Check the **Aliases** section if the name doesn't match exactly.
2. Look up the row in the **Routing table**. Contact the listed **project economist(s)** first — they are the day-to-day contact for that department.
3. If no individual economist is listed for the unit, or the question is escalated/managerial, contact the **Project Finance Manager (PFM)** for that team.
4. For questions that are *not* department-specific (project setup, system/process issues, budgeting, campus/fixed assets), use **Central functions** instead.
5. **Do not guess.** If a department is not in the table, say so and suggest the Project Finance Manager route or the Head of Project Controlling.

**Escalation path (Projektøkonomi):** project economist → Project Finance Manager (team) → Sektionschef (process or system) → Tina Holst Beck (Områdechef / Head of Project Controlling).
